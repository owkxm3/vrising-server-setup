## 夜族崛起服务器搭建先选路线：私人游戏、自己电脑开服，还是云服务器

先说结论：偶尔玩选私人游戏，长期联机选云服务器独立服；自己电脑开独立服只适合你懂端口映射、且电脑能长期开机的情况。

私人游戏的好处是零成本，存档在主机上，朋友通过 Steam 加入。缺点是主机退出游戏，其他人就进不去；主机网络不好，大家一起卡。这里有个很容易踩的坑：创建房间时不要勾“局域网服务器”，一旦勾选，只有同一局域网下的电脑能进，外地朋友会一直连接失败。

自己电脑开独立服，本质上和云服务器一样，只是把服务端跑在本机。省了租服务器钱，但要处理公网 IP、路由器端口映射、防火墙，还要保证电脑不关机。宿舍或家庭宽带没有公网 IP 时，这一步很容易卡住。

云服务器独立服适合“晚上下班或放学后朋友随时能进”的场景。服务端跑在云上，你的游戏客户端关不关都不影响。代价是月租，以及需要自己维护配置和备份。

## 用 Windows 云服务器 + VSM 搭建：8 个步骤

新手最省事的是 Windows 云服务器加 VSM 中文管理端。VSM 把下载服务端、更新、启动和配置编辑做成了图形界面，但它只支持 Windows，运行前需要装 .NET Runtime 6.0。

如果还没买服务器，先确认能选 Windows 系统再下单；装到一半发现只有 Linux 镜像，会多花一轮时间。👉 [查看腾讯云 Windows 云服务器活动档位](https://bit.ly/yunhuodong)

1. 在腾讯云买一台 Windows Server 云服务器，记下公网 IP，用远程桌面登录。系统盘和内存按上一节选，别选纯命令行镜像。
2. 安装 .NET Runtime 6.0 的 Windows Desktop Runtime x64 版本。缺这个，VSM 双击没反应或直接报错。
3. 下载 VSM 中文版，解压到一个你找得到的文件夹，双击 `V Rising Server Manager.exe`。
4. 首次打开会弹出创建服务器窗口；没弹出就点“添加服务器”。输入一个只在管理端显示的名称，然后点“更新服务器”，等控制台把服务端下载完。
5. 更新完成后点“启动服务器”，等大约 30 秒，再点“停止服务器”。这一步是让默认配置文件生成出来，不是让你现在就开始玩。
6. 点“服务器文件夹”，找到 `VRisingServer_Data\StreamingAssets\Settings`，把里面的两个配置文件复制到 `SaveData\Settings`。复制后这个目录里应该有四个文件：`adminlist.txt`、`banlist.txt`、`ServerGameSettings.json`、`ServerHostSettings.json`；前两个文本文件没有就自己新建，内容留空。
7. 回到 VSM 设置，勾选“自动加载设置文件”。然后用“服务器连接配置编辑器”和“游戏属性配置编辑器”改配置。服务器名称和存档名称在编辑器里改不了，要到 `SaveData\ServerHostSettings.json` 里改；存档名不懂就别动。
8. 在腾讯云控制台的防火墙/安全组和 Windows 防火墙里放行服务端配置中的 `GamePort` 和 `QueryPort`，再启动服务器。客户端用“公网 IP:GamePort”直连。RCON 先别开，等服务器能进了再说。

这一套流程的关键不是点“启动”，而是第 6 步的配置文件复制。VSM 默认从 `SaveData\Settings` 加载配置；你没复制，编辑器可能报加载错误，改了也不生效。

## 两个配置文件别改混：ServerHostSettings 和 ServerGameSettings

`ServerHostSettings.json` 管“服务器怎么被连接”，`ServerGameSettings.json` 管“游戏怎么玩”。改错文件，最常见的结果就是“明明改了却没效果”。

`ServerHostSettings.json` 里看这些：
- 服务器名称：默认是 `V Rising Server`，可以改成中文；游戏名称支持中文。
- 存档名称：不懂就保持默认，改错可能找不到存档。
- `GamePort` 和 `QueryPort`：安全组、防火墙、客户端直连都以这里为准。
- 密码、最大人数、RCON 开关和端口：按需改，RCON 不用就别开。

`ServerGameSettings.json` 里是玩法参数，比如难度、掉落、城堡限制等。VSM 的“游戏属性配置编辑器”可以可视化改，但保存前确认它加载的是 `SaveData\Settings` 里的文件，而不是默认模板。

`adminlist.txt` 放管理员 64 位 SteamID，`banlist.txt` 放封禁 ID。每行一个，别把 Steam 昵称填进去。

## 朋友进不来时，先查这 6 件事

先分清是私人游戏还是独立服。私人游戏先查“局域网服务器”有没有被勾上；独立服先查端口、防火墙和 IP 有没有填对。两者的排查顺序不一样，混着查只会浪费时间。

1. 私人游戏创建时有没有勾“局域网服务器”。勾了，外地朋友基本进不来；取消勾选再开。
2. 私人游戏联机时，优先让朋友从 Steam 好友头像右键选择“加入游戏”，而不是只发邀请。
3. 私人游戏联机一直连接失败，可以让所有联机者都开加速器再试；独立服直连则先把端口和防火墙查清楚，别一上来就怪加速器。
4. 只有一个朋友进不去，其他人都正常：让他用 Steam 的“验证游戏文件完整性”修客户端，再重试。
5. 独立服：腾讯云控制台的防火墙/安全组和 Windows 防火墙是否都放行了 `GamePort` 与 `QueryPort`。只放行一个，常见结果是能看到服务器但进不去。
6. 客户端填的是不是“公网 IP:GamePort”，密码有没有多空格，服务端是不是还在启动中。启动完成前连，会直接失败。

如果服务端启动日志里报配置错误，先把最近改过的 JSON 还原，再逐项改。不要一次改十几个参数，出问题很难定位。

## 坏档、死档和误操作：先备份，再删最后一个自动存档

大多数“坏档”不是整个存档全坏，而是最后一个自动存档写坏了。先复制一份到别的地方，再动手删文件。

一个常见的处理办法是：自己建的档自己进不去，或者连接时服务端无故崩溃，可以打开存档目录，按时间或文件名找到最后一个自动存档，例如 `AutoSave_2.save.gz`，把它删掉再进游戏。你的文件名不一定叫这个，按修改时间判断，删之前一定备份。

如果是“建档人能进，朋友一直连接失败”，这通常是联机配置问题。按上一节查局域网勾选、端口、加速器和客户端完整性，别急着删存档。

最后一招是“移花接木”：先新建一个确认所有人都能进的新档，退出游戏；分别打开新档和旧档的存档目录，把旧档的数据复制替换到新档里，再进新档。这个操作会覆盖新档数据，做之前把两个档都备份。它适合旧档还能读、但联机入口坏掉的情况，不适合已经物理损坏的存档。

日常维护最简单的办法：每次更新服务端、加模组、改配置前，先停服，把 `SaveData` 整个压缩备份。云服务器上的磁盘快照是另一层保险，但不能代替你自己能拿到的存档副本。

## 管理员和 RCON：能发公告，不等于能远程为所欲为

给管理员权限，最稳的是把对方的 64 位 SteamID 加进 `adminlist.txt`，或者在 VSM 的“GM 管理”里添加。填昵称没用，必须是 64 位 SteamID。

RCON 要在服务器连接配置里启用，设置密码和端口，需要时再绑定 IP。这个游戏的 RCON 只有两个常用指令：`announce` 发公告，`announcerestart` 发起重启倒计时。公告只能发英文；重启公告的参数只能填数字，但客户端会用本地语言提示重启信息。

所以别把 RCON 当成完整远程命令台。它能做的事情很有限，端口暴露到公网反而增加风险。用完关掉，密码别和远程桌面密码一样。

## FAQ：夜族崛起服务器搭建常见问题

**一定要买云服务器吗？**
不一定。两三个人偶尔玩，私人游戏足够；需要 24 小时在线、朋友随时进，才值得买云服务器。

**Windows 还是 Linux？**
新手选 Windows + VSM，图形界面少踩命令行坑；Linux 更省资源，但配置和更新都要自己敲命令。

**2 核 2G 能开吗？**
测试可以，Windows 下 2–4 人更建议 2 核 4G 起。人数多、模组多，优先加内存和带宽。

**朋友进服填什么地址？**
填“公网 IP:GamePort”。端口去 `ServerHostSettings.json` 里看，不要照抄别人的端口。

**服务器重启会丢档吗？**
正常停止一般不会。强制关机、更新中断、改配置前不备份，才容易出问题。先把 `SaveData` 备份养成习惯。

**需要开加速器吗？**
独立服直连先查端口和防火墙；私人游戏联机时，所有联机者都开加速器再试。先分清模式，再决定要不要开。
